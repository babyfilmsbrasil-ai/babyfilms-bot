# 🎬 Bot WhatsApp - Baby Films

Bot automatizado e humanizado de atendimento para a **Baby Films**.
Realiza a qualificação inicial de novos clientes, apresenta os vídeos informativos e passa o bastão diretamente para o **Cristiano**.

---

## 🚀 Como hospedar Gratuitamente na Nuvem (24h/dia)

Recomendamos utilizar o **Render.com** (plano gratuito):

1. Crie uma conta gratuita em [render.com](https://render.com).
2. Conecte sua conta do GitHub ou crie um novo **Web Service**.
3. Selecione o repositório ou envie esta pasta `babyfilms-bot`.
4. Configure as seguintes opções:
   - **Environment:** `Node` ou `Docker`
   - **Build Command:** `npm install`
   - **Start Command:** `node index.js`
   - **Instance Type:** `Free`
5. Clique em **Create Web Service**.

---

## 📲 Como Conectar o WhatsApp

1. Assim que o serviço estiver rodando, acesse a URL que o Render criar (ex: `https://babyfilms-bot.onrender.com`).
2. A tela exibirá o **QR Code** de conexão.
3. No seu celular, abra o **WhatsApp** > **Aparelhos Conectados** > **Conectar um aparelho**.
4. Aponte a câmera para o QR Code na tela.
5. Pronto! Uma vez conectado, você verá a mensagem de confirmação e o bot responderá 24 horas por dia, sem precisar do seu computador ligado.

---

## 💬 Fluxo Configurado

1. **Boas-Vindas:** Identificação transparente do assistente virtual e aviso de que o Cristiano assumirá o atendimento; pergunta da data e local.
2. **Identificação da Criança:** Coleta do nome e idade do(a) aniversariante.
3. **Transição & Vídeos Informativos:**
   - Informativo Babyfilms 2026: `https://youtu.be/HLIeDSifwVA`
   - Retrospectiva Maria Antônia: `https://www.youtube.com/watch?v=Co_VO4x0XH8`
4. **Fechamento & Transição:** Encaminhamento final e notificação para o Cristiano apresentar proposta e contrato.
